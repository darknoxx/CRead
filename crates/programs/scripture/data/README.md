# English Bible text

The 66 files in this folder are the English **Webster's World Bible (1913)**,
copied from the `bible_en/` folder of the EZScripture project. The text is in
the public domain and is therefore distributed with SCRIPTURE under the same
terms as the rest of CRead.

The Markdown shape is:

- `# Book name`
- `## Chapter N`
- `1. Verse text`

No Python or Qt code from EZScripture is included here; SCRIPTURE's reader is
an independent Rust implementation. The only source-level changes are
typographic apostrophes and em dashes normalised to the characters available in
CRead's VGA bitmap font.
